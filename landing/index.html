Invisibility Architecture

How screen exclusion works without black boxes.

Standard screen capture blockers call Chromium's built-in setContentProtection(true), which triggers Windows legacy WDA_MONITOR. This replaces the window with a noticeable black box in video streams.

YO-Assistant replaces that mechanism entirely with direct Win32 API calls, enforcing WDA_EXCLUDEFROMCAPTURE (0x11) across all native HWND surfaces so the screen sharing stream sees directly through the window.

✕ Traditional Tools
  • • Sets WDA_MONITOR (0x01)
  • • Creates a solid black box on screen share
  • • DWM drop shadow renders outline on drag
  • • Steals active focus on mouse click
✓ YO-Assistant Architecture
  • • Enforces WDA_EXCLUDEFROMCAPTURE (0x11)
  • • Underlying desktop paints 100% cleanly
  • • Zero OS window frame shadow
  • • Continuous foreground HWND focus return
Win32 API Chain: SetWindowDisplayAffinity(hwnd, 0x00000011) → EnumChildWindows(hwnd, applyAffinity) → SetWindowPos(HWND_TOPMOST, SWP_NOACTIVATE)
