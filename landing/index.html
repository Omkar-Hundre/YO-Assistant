How Clovi works
See it. Snap it. Solved.
Three keystrokes between you and the answer. No switching tabs, no typing, no wasted time.
1

Launch Clovi (always on top)

Clovi starts as an ultra-compact 210px capsule pinned at the top of your screen. It's invisible to all screen capture software.

2

Press Ctrl+Shift+S to snap

One global hotkey captures whatever question, code, or diagram is currently on screen — without ever losing focus on your exam browser.

3

Get the direct answer streamed instantly

Gemini Vision reads the problem and streams the direct answer, runnable code, or solution steps straight into the floating bubble above your screen.

Undetectable in every way
Built to be invisible.
Using the same Win32 API that Windows itself uses to exclude windows from screen capture.
🫥

Invisible to screen share

Uses Windows WDA_EXCLUDEFROMCAPTURE — Clovi never appears in Google Meet, Zoom, Teams, or any recording software.

🔒

Zero focus loss

Clovi uses WS_EX_NOACTIVATE so clicking on it never blurs your exam browser — no tab switch events, no focus-loss warnings.

📡

Invisible to proctors

No DOM injection, no browser extension, no background process attached to your exam tab. It lives completely outside the browser at the OS level.

🎯

Follows your eyes

Drag the capsule anywhere on screen. Position it at the exact corner that's most comfortable for quick glances without moving your head.

🌑

No telemetry

No sign-in, no analytics, no data sent anywhere. 100% local Electron app. Your API key and snapshots never leave your machine.

💾

Portable — no installer

Single .exe file. Drop it anywhere, run it, done. Nothing written to Windows Registry. Works on any Windows 10/11 machine.

FAQ
Frequently asked questions.
No. Clovi uses WDA_EXCLUDEFROMCAPTURE — the same native Win32 API Windows uses for DRM. It is completely absent from Google Meet, Zoom, Discord, Teams, OBS, Windows Game Bar, and all proctoring overlays tested.
Never. Clovi uses WS_EX_NOACTIVATE — clicking anywhere on Clovi does not steal focus from your browser. Your exam tab stays active the whole time.
100% free and MIT open-source. No subscription. No sign-in. You do need a free Gemini API key from Google AI Studio (takes 30 seconds, no credit card). After that, usage is free up to Gemini's generous free tier.
Anything visible on your screen — coding problems (Python, Java, C++, SQL), multiple-choice, math/STEM, essay prompts, data science, system design, and more. If Gemini Vision can read and understand it, Clovi can solve it.
Your screenshots go from your machine to the Gemini API directly (same as using Google AI Studio). Nothing is stored on any Clovi server — there is no Clovi server. The app is a local Electron process.
Currently Windows 10/11 only — the Win32 capture-exclusion API is what makes it genuinely undetectable. macOS and Linux builds are on the roadmap. Join the waitlist to be notified.
