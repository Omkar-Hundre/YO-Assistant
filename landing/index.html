How YO-Assistant Stays
Completely Invisible

Standard screen capture tools use legacy protection that produces a conspicuous black box during video streams. YO-Assistant bypasses this by configuring native Windows Desktop Window Manager (DWM) display affinities:

✓
WDA_EXCLUDEFROMCAPTURE (0x11): DWM renders the underlying desktop and apps directly without black boxes.
✓
Child HWND Recursion: EnumChildWindows propagates capture exclusion to all Chromium renderer surfaces.
✓
Pure CSS Shadows: Disables OS drop shadows (`hasShadow: false`) to eliminate drag outlines.
❌ Other Tools / setContentProtection(true) Black Box Artifact
